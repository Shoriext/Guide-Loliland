Выведение новых пчёл одна из основных задач мода forestry, так же их можно мутировать для открытия более лучших пчёл.

# Процесс выведения новых пчёл {#newbees}

Для того чтобы вывести свою первую пчелу, вам понадобится <item id="Forestry:apiculture" meta="0" count="1" />, так же желательно иметь шоколадную рамку(гиперсылка) для более быстрого распада матки. Например вам нужно вывести <item id="Forestry:beePrincessGE"/>, для этого кладете <item id="Forestry:beePrincessGE"/> и <item id="Forestry:beePrincessGE"/>, с шансом после распада матки выпадет принцесса или трутень нужной вам пчелы.

# Мутации {#mutation}

Мутация это скрещивание одного вида с другим, у каждой мутации есть шанс, его можно посмотреть в INDEX наведясь на нужную вам пчелу и нажать R, для повышения этого шанса можно использовать в пасеке рамки (гиперсылка). Если мутация не происходит, то на выходе получается 'чистокровное' потомство.
:::callout{type="tip"}
Рекомендация: ново-выведенный гибрид пару раз скрестить с такими же гибридными трутнями для укрепления породы.
:::
