В этом разделе речь пойдет о автоматизации хранения, доставки и создания ресурсов помощью МЭ-системы.

# Что такое МЭ-Система {#me_info}

**МЭ-система** – это мощный инструмент, позволяющий компактно хранить, а также создавать и передавать огромные количества ресурсов за считанные секунды. С ее помощью можно заменить нагромождение сундуков и труб, а также сэкономить значительное количество времени, создавая предметы в один клик.

:::callout{type="tip"}
Для своей работы система требует EU. Потребление энергии зависит от количества подключенных компонентов сети.
:::

# Начала автоматизации {#me_basis}

Начальная МЭ-система не требует больших вложений и доступна на раннем этапе игры. Это отличный вариант для оптимизации хранения ресурсов.

Основой для постройки МЭ-системы служат следующие блоки:

:::item-card{item="appliedenergistics2:tile.BlockController"}
– Сердце и главный компьютер, именно к [контроллеру](guide:primer:controllers) подключаются все компоненты любой МЭ-сети, а также EU энергия.
:::
:::item-card{item="appliedenergistics2:tile.BlockDrive"}
– Основное хранилище всех ресурсов МЭ-системы. Для его работы необходимо положить внутрь [ячейки хранения](guide:primer:storage-cell).
:::
:::item-card{item="appliedenergistics2:item.ItemMultiPart" meta="380"}
– [Терминал](guide:primer:terminals) взаимодействия с системой. Дает доступ ко всем ресурсам и рецептам внутри.
:::
:::item-card{item="appliedenergistics2:item.ItemMultiPart"}
– Основной функциональный блок, который используется для подключения элементов системы. Представлен несколькими [типами](guide:primer:cabels_busbars).
:::

:::callout{type="warning"}
Все элементы системы должны быть связаны между собой и подключены к контроллеру. В противном случае система работать не будет.

:::callout{type="warning"}
Каждая система поддерживается лишь одним кластером контроллеров. Если два и более контроллера соединяются в одну сеть, то она не будет работать, а <item id="appliedenergistics2:tile.BlockController" /> загорится красным светом.
:::

Далее МЭ-систему можно расширять и масштабировать, добавляя различные функции, с помощью соответствующих механизмов:

:::block-card{item="appliedenergistics2:item.ItemMultiPart" meta="260"}
– Базовая [шина](guide:primer:cabels_busbars), поставляет предметы.
:::
:::block-card{item="appliedenergistics2:item.ItemMultiPart" meta="240"}
– Базовая [шина](guide:primer:cabels_busbars), забирает предметы
:::
:::block-card{item="appliedenergistics2:tile.BlockInterface"}
– [Интерфейс](guide:primer:interfaces) взаимодействия с системой, основной механизм автоматизации создания.
:::
:::block-card{item="appliedenergistics2:tile.BlockMolecularAssembler"}
– Начальный [сборщик](guide:primer:assemblers), который является автоматической заменой верстака.
:::

# Каналы {#canals}

Каналы – это подключения компонентов МЭ-системы. Каждый компонент занимает один канал.

Обычно для соединения компонентов в МЭ-систему используют разновидности [кабелей](guide:primer:cabels_busbars). Если кабель достигает лимита подключений, дальние (от контроллера) механизмы не будут подключены.

:::callout{type="tip"}
Каждый функциональный **блок** МЭ-системы проводит каналы, обычно до 8. Для соединения стоящих впритык компонентов системы не обязательно использовать кабели, они и так соединятся.
:::

:::callout{type="tip"}
<item id="appliedenergistics2:tile.BlockController" /> проводит неограниченное количество каналов.
:::

:::callout{type="tip"}
Вы можете использовать <item id="loli_technologies:item.ItemVisualiser" /> для отслеживания количества текущих подключений и состояния сети.
:::
