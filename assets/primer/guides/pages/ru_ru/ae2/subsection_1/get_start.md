# Первая МЭ-система {#pervaya-me-sistema}

Для создания первой МЭ-системы непонадобится много рессурсов вам потребуется:

- <item id="appliedenergistics2:tile.BlockController" />, он будет сердем системы и хранить энергию и [каналы](guide:primer:cabel)
- <item id="appliedenergistics2:tile.BlockDrive" />, для хранения ячеек
- <item id="appliedenergistics2:item.ItemMultiPart" />, для подключения остальных фунциональных блоков
- <item id="appliedenergistics2:item.ItemMultiPart" meta="360" />, для доступа к хранилищу
