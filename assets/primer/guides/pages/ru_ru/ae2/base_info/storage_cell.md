В данной статье речь пойдет о ячейках, их видах и способах хранения ресурсов.

# Что такое ячейка {#cell-info}

**Ячейка** – это «жесткий диск», куда записывается информация о хранящихся ресурсах. В МЭ-системе они хранятся в электронном виде. У ячеек есть три параметра:

- Кол-во байтов
- Кол-во типов
- Вид хранимых ресурсов

# Что такое байты и типы {#cell-byte-type}

**Байт** – это условная единица измерения вместимости. Чем больше у ячейки байтов, тем больше ресурсов она сможет хранить.

:::callout{type="tip"}
Если закончатся байты, то ячейка переснает принимать предметы.
:::

**Тип** – это уникальный хранимый ресурс. Чем больше типов у ячейки, тем больше уникальных предметов она может хранить.

:::callout{type="tip"}
Если закончатся типы, то ячейка переснает принимать новые уникальные предметы, но продолжит принимать уже имеющиеся.
:::

# Какие виды ячеек существуют {#kakie-vidy-yacheek-suschestvuyut}

Для каждого вида ресурсов нужна ячейка определенного вида. Всего их существует четыре:

- Предметная, например <item id="appliedenergistics2:item.ItemBasicStorageCell.1k" />
- Жидкостная, например <item id="appliedenergistics2:item.ItemBasicStorageCell.fluid1k" />
- Газовая, например <item id="appliedenergistics2:item.ItemBasicStorageCell.gas1k" />
- Эссенций, например <item id="appliedenergistics2:item.ItemBasicStorageCell.aspect1k" />

:::callout{type="tip" }
Для каждого вида ячеек существует продвинутый аналог – **Бесконечные ячейки**, способные хранить бесконечное количество ресурсов своего вида, но так же ограниченные по типам.
:::

:::item-card{item="appliedenergistics2:item.ItemCreativeStorageCell.aspect"}
– уникальная ячейка, содержащая **бесконечное** количество эссенции всех типов, на которые настроена. Можно разметить, использовав <item id="Thaumcraft:ItemWispEssence" /> или перетаскивая <tooltip content="Все аспекты можно отобразить, \n введя в поиске «аспект»">аспекты</tooltip> из Index.
:::

# Разметка ячеек {#cell-formating}

Если вам необходимо сделать так, чтобы ячейка принимала только конкретные предметы, вы можете разметить ее, используя <item id="appliedenergistics2:tile.BlockCellWorkbench" />, указав нужные типы предметов.
