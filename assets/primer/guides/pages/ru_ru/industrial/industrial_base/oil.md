Что такое нефть? В этой статье вы узнаете всё про неё.

# Основная информация {#info_oil}

Нефть - один из важнейших ресурсов, которые понадобятся на протяжении всей игры. Она добывается с помощью [нефтянной вышки](guide:primer:oil-rig-1), а для работы этой многоблочной структуры требуется сырьё, в качестве которого выступают месторождения нефти.

# Месторождения нефти {#info_oil_claster}

Месторождения нефти находятся в других измерениях, в которых добывать нефть не очень удобно, так что потребуется собрать информацию о месторождениях. Для этого нам понадобится <item id="lolienergistics:logging_probe" />.

:::block-card{item="lolienergistics:logging_probe"}
Сканирует местность на наличие месторождений нефти.
Для работы требует энергию
:::

Месторождения бывают трёх уровней:

- Альфа
- Бэтта
- Гамма

От уровня зависит количество нефти, которое можно добыть. Для эффективной работы [нефтянной вышки](guide:primer:oil-rig-1), нужно следить за доступными месторождениями.

| Уровень месторождения | Уровень нефтянной вышки |
| --------------------- | ----------------------- |
| Альфа                 | Начаная с 1 уровня      |
| Бэтта                 | Начаная с 2 уровня      |
| Гамма                 | Начаная с 3 уровня      |

При добыче из месторождений более высокого уровня при неподходящем уровне [нефтянной вышки](guide:primer:oil-rig-1) эффективность добычи будет снижаться.

Для просмотра списка найденных месторождений используется <item id="lolienergistics:deposit_registry" />
