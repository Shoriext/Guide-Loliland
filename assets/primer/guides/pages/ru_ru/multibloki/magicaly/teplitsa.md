Мультитеплица – промежуточный этап генерации маны, позволяет помещать в себя цветы генерирующей флоры, которые за счет [улучшений](guide:primer:tep-4#upgrade_table) будут давать в разы больше маны, чем вне её.
:::callout{type="tip"}
Данную структуру можно построить при помощи жезла <item id="loli_utility:structure_builder" />
:::

# Работа с мультитеплицей {#work}
Для начала генерации маны в мультитеплице необходимо подать в нее <tooltip content="подвести энергию можно к любому блоку теплицы.">энергию</tooltip>, положить цветы генерирующей флоры в 8 верхних слотов и подавать необходимое <tooltip content="например: еда - для гурмарилисов \nгорючее топливо - для пламени края">топливо</tooltip> для цветов, которые вы положили.\
Для вывода маны из теплицы можно использовать <item id="lolimagically:stray_ethereal_spark">искры</item> или <item id="Botania:spreader" />.
:::callout{type="tip"}
Чтобы выводить ману с помощью распространителя следует поставить его **вплотную** к мультитеплице
:::
