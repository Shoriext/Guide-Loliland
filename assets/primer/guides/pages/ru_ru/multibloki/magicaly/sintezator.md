Алхимический синтезатор - структура, позволяющая создавать различные предметы за счет маны и аспектов.

# Работа с синтезатором {#work}

Для подачи аспектов в алхимический синтезатор можно использовать <item id="appliedenergistics2:tile.BlockInfusionProvider" />, а так же различные банки с эссенцией. \
Подавать ману можно через <item id="lolimagically:stray_ethereal_spark">искры</item>, либо через <item id="Botania:spreader" />.

# Доступные улучшения {#upgrade_table}
| Улучшение                               | Что делает  |
| :------------------------------------- | :---------- |
| <item id="lolimagically:magic_stack_upgrade" />          | Позволяет крафтить стаком |
| <item id="lolimagically:asgard_upgrade" />        | Убирает потребность в мане |
| <item id="loli_technologies:item.ItemSealAzanor" /> | Убирает потребность в аспектах    |
| <item id="lolimagically:item_upgrade" /> | Увеличивает скорость производства    |

:::callout{type="tip"}
Данную структуру можно построить при помощи жезла <item id="loli_utility:structure_builder" />.
:::
:::callout{type="tip"}
В случае разрушения одного из блоков вы можете поставить его на место и нажать по структуре жезлом минимум на **50 вис**.
:::
