В данном разделы вы узнаете, как работать с мультиблочными структурами.

# Основная информация {#info}

На нашем сервере существует механика многоблочных структур, при которой механизм - это не один блок, а конструкция из большего числа блоков.

Для работы с многоблочными структурами существует несколько полезных инструментов:
:::item-card{item="loli_utility:structure_builder"}
Основной инструмент для постройки структур, что бы открыть интерфейс нужно нажать <hotkey bind="ПКМ" modifiers="shift" />
для постройки нажать <hotkey bind="ПКМ" />
:::

:::item-card{item="lolienergistics:quantum_assembly_tool"}
Позволяет активировать структуру, если она была разрушена, без полной перестройки
:::

:::item-card{item="loli_dragon_might:alien_structure_activator"}
Работает как <item id="lolienergistics:quantum_assembly_tool" />, но в отличие от него, позволяет восстанавливать структуры из LoliDragonMight
:::
