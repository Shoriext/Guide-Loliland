В данном разделы речь пойдёт о том, как работать с мультиструктурами.

# Основная информация {#info}

На нашем сервере существует большое количество уникальны мультиструктур.

Для работы с ними существует несколько полезных инструментов:  
:::item-card{item="loli_utility:structure_builder"}
Основной инструмент для постройки структур. Чтобы открыть интерфейс нужно нажать <hotkey bind="ПКМ" modifiers="shift" />
для постройки нажать <hotkey bind="ПКМ" />.
:::

:::callout{type="tip"}
Для корректной работы рекомендуем строить мультиструктуры в пределах одного чанка.
:::

:::item-card{item="lolienergistics:quantum_assembly_tool"}
Позволяет активировать структуру индустриализации без полной перестройки, если одна из них была разрушена.
:::

:::item-card{item="loli_dragon_might:alien_structure_activator"}
Работает как <item id="lolienergistics:quantum_assembly_tool" />, но в отличие от него, позволяет восстанавливать структуры эпохи драконов.
:::

:::callout{type="warning"}
Мультиструктуры нельзя повернуть.
:::
