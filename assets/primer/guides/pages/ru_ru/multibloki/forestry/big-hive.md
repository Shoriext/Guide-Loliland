Большой улей - многоблочная структура, которая служит улучшенной версией <item id="Forestry:apiculture" meta="0">пасеки</item>, позволяя размещать в себе различные улучшения, благодаря которым можно воссоздавать необходимые условия работы пчел и не только.
:::callout{type="tip"}
Данную структуру можно построить при помощи жезла <item id="loli_utility:structure_builder" />.
:::
# Улучшения большого улья {#bighive_upgrades_1}

Улучшениями для большого улья служат различные блоки, для их установки необходимо заменить любой <item id="Forestry:alveary" /> необходимым вам блоком улучшения.

# Возможные улучшения {#bighive_upgrades_2}
| Улучшение                               | Что делает  |
| :------------------------------------- | :---------- |
| <item id="ExtraBees:alveary" meta="1" />          | Позволяет помещать в улей рамки |
| <item id="ExtraBees:alveary" />  | Использует <tooltip content="Доступные мутагены: \nПесок душ \nАстральная жемчужина \nГлаз края">мутагены</tooltip> для увеличения шанса мутации   |
| <item id="Forestry:alveary" meta="4" /> | <tooltip content="За счет энергии">Повышает температуру</tooltip> в улье     |
| <item id="Forestry:alveary" meta="3" /> | <tooltip content="За счет энергии">Понижает температуру</tooltip> в улье     |
| <item id="Forestry:alveary" meta="5" /> |<tooltip content="Помещая лаву - понижается влажность и немного поднимается температура \nПомещая воду - повышается влажность и немного падает температура">Изменяет влажность</tooltip> в улье  |
| <item id="Forestry:alveary" meta="6" /> | Убирает возможность мутации в улье    |
| <item id="ExtraBees:alveary" meta="4" /> | Позволяет помещать в улей <tooltip content="Печатные платы так же улучшают различные характеристики улья, например: производительность, шанс мутации, скорость вырождения">печатные платы</tooltip>    |
| <item id="ExtraBees:alveary" meta="6" /> |Запитывает улей <tooltip content="При подаче на него энергию электротрансформатор будет запитывать все блоки в улье, которые требуют энергию">энергией</tooltip>    |
