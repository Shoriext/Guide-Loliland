# Как работать

## Команды git

`git status`
показывает изменение файлов

`git add .`
добавляет все файлы для отправки. Также поддерживает место точки имя файла если вы хотите добавить только один файл

`git commit -m "Описание того что вы сделали"` Служит для коментирования добавленных файлов

`git push` отправляет изменения

`git pull` вытягивает изменения других

Если есть конфликт и не даёт отправить напишите @Shoriext

Механизм работы

1. git pull
2. Пишете гайд
3. git add . или название файла
4. git commit -m "Описание" лучше подробно
5. git push
